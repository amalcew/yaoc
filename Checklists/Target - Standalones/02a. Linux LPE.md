#### Checklist
- [ ] `sudo -l`
- [ ] Run `linpeas.sh`
- [ ] Current user information (groups, perms, etc.)
- System data
	- [ ] Hostname
	- [ ] Networking details (routes, hosts , interfaces)
	- [ ] Print `$PATH`
	- [ ] `env` variables
	- [ ] List network connections (TCP & UDP) (e.g. with `netstat`)
	- [ ] Running processes (with `pspsy`)
	- [ ] Other users present in the system (`/home`, `/etc/passwd` `bash` sessions, `lstlog`, `w`, `getent passwd`)
	- [ ] Kernel and distro release details (kernel exploits)
	- [ ] Cron jobs
	- [ ] Writable service files (`systemd`)
	- [ ] Mounted filesystems (`lsblk`, `df -h`)
- Filesystem:
	- [ ] Locate all SUID/GUID files
	- [ ] Locate files with POSIX capabilities
	- [ ] List all world-writable files
		- [ ] Writable `/etc/sudoers`
		- [ ] Writable `/etc/passwd`
		- [ ] Readable `/etc/shadow`
		- [ ] Writable scripts run by root
		- [ ] Writable shared libraries (`*.so`)
		- [ ] Writable directories in `$PATH`
		- [ ] Relative path execution in cron/systemd/scripts
		- [ ] `LD_PRELOAD` / `LD_LIBRARY_PATH` abuse opportunities
	- [ ] Locate mails
	- [ ] Find/list all accessible *.plan files and display contents
	- [ ] Find/list all accessible *.rhosts files and display contents
	- [ ] Show NFS server details (`no_root_squash` exports)
	- [ ] Locate _.conf and_.log files containing keyword supplied at script runtime
- Credential hunting
	- [ ] Services config files (e.g. Wordpress)
	- [ ] SSH keys
	- [ ] Database-stored credentials
	- [ ] Suspicious custom files in `/home`, `/opt`, `/tmp`, `/etc`
	- [ ] Command history
	- [ ] Memory/process stored credentials (`ps auxww`, `strings /proc/*/environ`)
- [ ] Test default/weak credentials for running services
- Platform/software specific tests:
	- [ ] Checks to determine if we're in a Docker container
	- [ ] Checks to see if the host has Docker installed
	- [ ] Checks to determine if we're in an LXC container
