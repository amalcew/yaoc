#### Checklist
- **External services enumeration**
	- [ ] `nmap` all TCP ports scan
	- [ ] `nmap` top UDP ports scan
	- [ ] `nmap` targeted services scan (`-sV`, `-sC`)
	- [ ] Collecting general information (hostname, IPs, banners, etc.)
	- [ ] Exposed repositories (`.git`/`.svn`/`.hg`)
	- [ ] Vhost/subdomains enumeration
	- SQL database  (e.g. via `mysql` CLI):
		- [ ] Credentials hunting
		- [ ] DB user impersonation
		- [ ] Command execution
		- [ ] Arbitrary file write (e.g. revshell/SSH key upload)
		- [ ] Database record overwrite (auth bypass)
	- SMB/FTP
		- [ ] Open shares/Anonymous access
		- [ ] Writable shares (file upload abuse)
	- SNMP:
		- [ ] Enumerate community strings
		- [ ] `snmpwalk` scan
		- [ ] Process/software enumeration
	- SSH
		- [ ] `nmap` `ssh-hostkey` enumeration 
	- SMTP/IMAP:
		- [ ] Mailbox enumeration/access
	- HTTPS/TLS
		- [ ] Certificate SAN/domain enumeration  
		- [ ] Alternate hostname discovery  
	- [ ] Other service-based exploitation
- **Web-based footprinting**
	- [ ] Directory fuzzing 
		- [ ] Fuzzing with extensions: php/aspx/jsp/cgi, backups: `.bak`, `.old`, `.zip`, etc.
		- [ ] Recursive fuzzing
	- [ ] Parameter discovery
	- [ ] Verb tampering (PUT/DELETE/etc.)
	- [ ] Map endpoints (`robots.txt`, `sitemap.xml`, APIs, etc.)
	- [ ] Information disclosure (e.g. via `phpinfo`)
	- [ ] Identify webstack via default pages (e.g. error pages)
	- [ ] CMS scan (e.g. using `wpscan`)
	- [ ] Known exploit (CVE + PoC sanity check)
		- [ ] Verify other PoCs (if `exploit-db` not working)
	- [ ] Front-end source code analysis
	- File upload:
		- [ ] Identify bypass strategy
		- [ ] `.htaccess` bypass
		- [ ] `.zip`/`phar`/etc. bypass
		- [ ] Webshell/revshell upload
		- [ ] SSH key injection into `authorized_keys`
		- [ ] Malicious plugin upload
	- Path traversal:
		- [ ] Users enumeration
		- [ ] Internal (e.g. `proc`) enumeration via LFI
		- [ ] Stored credentials & keys extraction
		- [ ] RFI revshell upload
		- [ ] LFI2RCE
		- [ ] Log/config poisoning
	 - [ ] Broken Access Control abuse
	 - [ ] Session tampering (`JWT` attacks, weak crypto algorithms etc.)
	 - [ ] Command/Code injection
	 - [ ] SQL/NoSQL injection
	 - [ ] SSTI
	 - [ ] XXE
	 - [ ] Insecure deserialization (e.g. using `ysoserial`)
	 - SSRF:
		 - [ ] Hash stealing (e.g. using `responder`)

	 - [ ] Type juggling
	 - [ ] Mass assignment

	- [ ] Usernames collection
	- [ ] Custom password wordlist generation (e.g. "seasonal" wordlists, `cewl` wordlists)

	- [ ] Default credentials search (app/CMS/admin panels, device web UIs/documentation)
	- [ ] Credentials reuse & credential stuffing
	- [ ] Account recovery mechanisms abuse
